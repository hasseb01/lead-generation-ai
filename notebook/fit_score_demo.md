# Fit Score demo: before / after

Reproduction of the exact gap documented in `SaaSquatch_Leads_Product_Analysis.md` §5:
searching Industry = "Software" in New York City on the live SaaSquatch Leads product
returned mostly personal-injury law firms and a generic "Consultant" instead of software
companies. This walks through `src/lib/scoring.ts` against that same query, using the
mock dataset in `src/lib/mockPlaces.ts` (`getMockPlaces("Software", "New York City")`),
which mirrors the actual company names observed in the live product's results.

To reproduce live: run `npm run dev`, open http://localhost:3000, search
Industry=`Software`, Location=`New York City`.

## Reading the scores

Score = category-match (40 pts) + similarity (0–40 pts, scaled from token-overlap or
OpenAI embedding cosine similarity) + has-website (10 pts) + has-phone (10 pts).

The five real matches score 63–73 not because they're a perfect semantic match to
"Software" (the token-overlap fallback caps out well under 1.0 for a one-word industry
query), but because the rule-based category-match signal alone is enough to clear the
default 40-point threshold and separate them cleanly from the law-firm noise, which
scores 0–20. Setting `OPENAI_API_KEY` raises the similarity signal's precision further
without changing this ranking.
